## Human-Earth Resilience Alliance
Open infrastructure for genetic stewardship. We maintain Sporechain, a minimal AT Protocol lexicon for signed biodiversity records rooted in formal taxonomy. It provides a shared federation layer for cultivators, seed libraries, researchers, and gene banks.

HERA is the first federation built on Sporechain. We’re building app views for cultivators and seed traders, labeling systems for taxonomic verification and provenance attestation, and bridges to Darwin Core, GBIF, and related biodiversity standards. We steward the protocol and aim to be one node among many.
