## Human-Earth Resilience Alliance
Tending open infrastructure for biodiversity commons. We maintain Sporechain, a minimal AT Protocol lexicon for signed biodiversity records keyed to scientific nomenclature — a shared layer for cultivators, seed libraries, seed keepers, researchers, and gene banks.

HERA is the first federation built on Sporechain. We're building app views for cultivators and seed traders, tools for taxonomic verification and provenance attestation, and bridges to Darwin Core, GBIF, and related biodiversity standards. We steward the lexicon and aim to be one node among many.
